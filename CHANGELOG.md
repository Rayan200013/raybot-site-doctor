# Changelog

## 0.1.0 (November 2026)

The first version: eight read-only tools and one prompt.

- `check_page`, `check_sitemaps`, `check_site` and `check_structured_data`, which need only the network.
- `measure_speed`, `check_accessibility`, `check_phone_fit` and `check_page_errors`, which use the Chrome or Edge on the computer.
- The `checkup` prompt: all eight on a site, one report.
- `robots.txt` followed, with `ignore_robots_txt` for a site the user owns, said at the top of the report when used.
- schema.org vocabulary 30.1.
